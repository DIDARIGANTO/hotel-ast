# AST Hotels — сайт сети

Статический сайт сети из трёх объектов в Астане: AMINA Hotel, City Line Hotel
и Botanic Garden Apartments. Девять HTML-страниц, без сборки и без бэкенда.
Формы ничего не отправляют на сервер: они собирают текст заявки и открывают
WhatsApp нужного отеля. Интерфейс на трёх языках — русский, казахский,
английский; выбор языка хранится в `localStorage` и читается из `?lang=`.

## Как открыть

Локально страницы открываются **только через http-сервер**: разметка
подключает ES-модули, по протоколу `file://` браузер их не загрузит и
страница останется пустой. Порядок запуска — в разделе «Локальный просмотр».

## Как залить на хостинг

Сборка не нужна. Содержимое корня проекта копируется в корень сайта как есть,
с сохранением структуры папок; входная страница — `index.html`. Подойдёт любой
хостинг статики. Требования к серверу:

- отдавать `.js` с типом `text/javascript` (иначе модули не подключатся);
- HTTPS — иначе браузер ругается на смешанное содержимое, потому что шрифты
  и фотографии грузятся по https.

Внешние ресурсы: Google Fonts (Playfair Display, Inter) и фотографии Unsplash.
Без интернета сайт работает, но без шрифтов и картинок. Папки `docs/`,
`tests/` и `tools/` на хостинг выкладывать не нужно.

## Как поменять цену или телефон

Правится один файл — `assets/js/hotels.js`.

- цена категории — поле `price` нужного номера;
- цена «от» на карточке отеля — поле `priceFrom`; оно должно совпадать
  с самой дешёвой категорией, это держит тест;
- телефон — поля `phone`, `phoneAlt` (только Botanic) и `whatsapp`;
  в `whatsapp` номер пишется цифрами без плюса и пробелов: `77013353530`;
- сроки и размер акции — поле `promo`;
- дополнительные услуги — массив `EXTRAS`, уровни клуба — `CLUB_LEVELS`.

После правки телефона его надо поменять и в разметке — в футере всех девяти
страниц и на `contacts.html` номера стоят текстом и в ссылках `tel:`.
Расхождение поймает `python3 tools/check.py` (проверка «телефоны»).

Цену в разметке искать не нужно: она есть только в таблице сравнения на
`hotels.html`, всё остальное рендерится из данных.

## Как заменить фотографии

Сейчас все изображения ведут на Unsplash. Чтобы поставить свои:

1. Положить файлы в `assets/img/` — например, `amina-hero.jpg`,
   `amina-standard.jpg`. Разумный размер: hero — до 1920 px по ширине,
   карточки и галереи — до 1200 px, jpg с качеством 80.
2. В `assets/js/hotels.js` заменить ссылки на относительные пути:
   `hero` у отеля и `img` у каждого номера — например,
   `hero: 'assets/img/amina-hero.jpg'`.
3. Галереи на страницах отелей заданы прямо в разметке: в `amina.html`,
   `cityline.html` и `botanic.html` найти блок `<div class="gallery"
   data-lightbox>` и поменять `src` у каждого `<img>`.
4. Hero главной — `<img>` внутри `.hero__media` в `index.html`; снимки
   в блоках предложений — `offers.html`, они тоже заданы в разметке.
5. В каждом `alt` описать, что на снимке: alt читают программы чтения
   с экрана, и он же виден, если картинка не загрузилась.

## Как вставить карту 2ГИС в contacts.html

На `contacts.html` под заголовком «Три метки в одном городе» стоит блок
`<div class="map">` с заглушкой. Порядок действий:

1. Собрать виджет в конструкторе карт 2ГИС: добавить три метки по адресам
   объектов и получить готовый код `<iframe>`.
2. В `contacts.html` заменить содержимое `<div class="map">` — весь блок
   с текстом заглушки — на этот `<iframe>`.
3. Пропорции и рамку задаёт CSS-класс `.map`, у самого `<iframe>` атрибуты
   `width`/`height` можно не ставить: правило `.map iframe` растянет его
   на всю ширину блока.
4. Полезно добавить `loading="lazy"` и `title="Карта отелей AST Hotels"` —
   карта не будет тормозить загрузку страницы и получит подпись.

Координаты объектов, если карта собирается вручную, лежат в поле `coords`
в `hotels.js`.

## Как поменять фирменные цвета

Все цвета — переменные в самом начале `assets/css/style.css`, блок `:root`.
Больше нигде значения цветов не повторяются.

| Переменная | Где видно |
|---|---|
| `--indigo` | тёмные секции, шапка при скролле, футер, тёмные кнопки |
| `--indigo-soft` | наведение на тёмную кнопку |
| `--gold` | акценты: черта надзаголовка, звёзды рейтинга, главная кнопка |
| `--gold-dim` | текст надзаголовка, наведение на золотую кнопку |
| `--sand` | светлые секции-подложки |
| `--graphite` | основной текст |
| `--muted` | вторичный текст, подписи |
| `--line`, `--line-dark` | рамки на светлом и тёмном фоне |

Рядом лежат шрифты (`--serif`, `--sans`), вертикальный ритм (`--step`),
поля контейнера (`--gutter`), максимальная ширина (`--maxw`) и скругление
(`--radius`). Шрифты меняются в двух местах: переменная в CSS и ссылка на
Google Fonts в `<head>` каждой страницы.

## Проверки

Node в этом окружении нет, поэтому тесты прогоняются в браузере, а
файловые проверки — скриптом на python3.

**1. Тесты в браузере.** Нужен локальный сервер (см. следующий раздел),
затем открыть:

```
http://localhost:8090/tests/tests.html
```

Страница печатает строки `PASS` / `FAIL` по каждому тесту, а внизу итог вида
`ИТОГО: 15 пройдено, 0 провалено`. Прогоняются наборы `tests/hotels.test.js`
(данные сети) и `tests/booking.test.js` (расчёт брони). Набор
`tests/i18n.test.js` к странице прогона не подключён: полноту словаря
сплошняком проверяет `tools/check.py`.

**2. Статические проверки.**

```bash
cd ~/Desktop/HOTEL-AST && python3 tools/check.py
```

Скрипт проверяет пять вещей: все ключи `data-i18n` из разметки заведены в трёх
языках и лишних ключей в словаре нет; внутренние ссылки ведут на существующие
файлы; в разметке нет зашитых цен (кроме таблицы на `hotels.html`); телефоны
на страницах совпадают с `hotels.js`; каждая страница подключает `ui.js`,
`i18n.js` и `pages.js`. Отчёт печатается строками `OK` и `ОШИБКА`, при
нарушениях код возврата — 1.

Обе проверки стоит прогонять после любой правки данных или разметки.

## Локальный просмотр

macOS не даёт локальному серверу читать файлы с `~/Desktop`, поэтому проект
сначала копируется в другую папку и сервер поднимается уже там:

```bash
rsync -a --delete ~/Desktop/HOTEL-AST/ /tmp/hotel-ast/ && cd /tmp/hotel-ast && python3 -m http.server 8090
```

Дальше открыть `http://localhost:8090/index.html`. Правки делаются в
`~/Desktop/HOTEL-AST`, после каждой копию нужно обновить — повторить команду
`rsync` (сервер при этом можно не перезапускать).

## Параметр ?noanim

Блоки на страницах появляются по мере прокрутки. Для скриншотов и печати это
мешает: то, что ещё не показалось, попадёт в кадр прозрачным. Добавьте к
адресу `?noanim` — анимация выключится и всё содержимое будет видно сразу:

```
http://localhost:8090/index.html?noanim
```

Параметр совмещается с выбором языка: `?noanim&lang=en`. Отдельно включать
его не нужно, если в системе стоит «уменьшить движение» — тогда анимация
выключена сама.
